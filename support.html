Getting Started

  1. Tap the + button and choose New Position.
  2. Enter a stock symbol (e.g., AAPL, TSLA) and a date.
  3. Tap into your position and use the toolbar at the bottom to add legs: +Stk (buy stock), −C (sell call), +P (buy put), etc.
  4. As you trade, close or roll legs to keep your position up to date.

Frequently Asked Questions

Do I need an API key to use the app?

No. PositionCashFlow is fully functional without any external service. You can create positions, add legs, record trades, close, roll, import from CSV, and export your data — all without an API key. All premium, price, and quantity information can be entered manually.

Live market pricing is an optional feature for users who want automatic stock and option quotes displayed alongside their positions.

How do I enable live market pricing?

If you'd like automatic price data:

  1. Visit polygon.io and create a free account.
  2. Copy your API key from the Polygon.io dashboard.
  3. In the app, open the ellipsis menu (…) and tap Settings.
  4. Paste your API key and tap Done.

The free Polygon.io tier provides previous trading day's close for stocks. Option quotes require a paid Polygon.io plan (Options Starter or higher). Without a paid plan, you can still enter option prices manually when adding or closing legs.

Stock or option prices aren't loading

If you've added an API key but prices aren't appearing, check the following:

  1. Open Settings and tap the eye icon to verify your key is correct.
  2. Stock data uses the free tier — prices won't update during weekends or holidays.
  3. Option quotes require a paid Polygon.io plan. On the free tier, stock prices will appear but option prices won't.

If you don't need live pricing, you can simply remove the API key from Settings. The app will skip all network calls and you can enter prices manually.

How do I import ThinkorSwim trades?

In ThinkorSwim, export your trade history as a CSV file. Then in PositionCashFlow:

  1. Tap + and choose Load CSV Data.
  2. Select your CSV file from the file picker.
  3. The app will parse and display the imported records.
  4. When adding legs to a position, use Fill from CSV to match imported entries.
What is "Position Value"?

Position Value is the estimated liquidation value of your position: what you'd receive if you closed all open legs at current market prices, combined with your net cashflow. For options, each contract represents 100 shares.

This field only appears when live pricing is enabled and prices are available for all open legs. Without an API key, your net cashflow (the sum of all recorded credits and debits) is always shown.

How do I roll an option?

Tap into a position, find the open leg you want to roll, and tap Roll. This closes the existing leg and opens a new one at the strike and expiration you choose. The net credit or debit is recorded as a single roll transaction.

How do I back up my data?

Tap the ellipsis menu (…) and choose Export Data. This creates a JSON file containing all your positions, legs, and transactions. Use the share sheet to save it to Files, AirDrop it, or email it to yourself. To restore, use Import Data and select the JSON file.

Can I delete a position or transaction?

Yes. Swipe left on any position in the list, any transaction in the detail view, or any closed leg to delete it. This action cannot be undone, so back up your data first if you're unsure.
