Getting Started

  1. Tap the + button and choose New Position.
  2. Enter a stock symbol (e.g., AAPL, TSLA) and a date.
  3. Tap into your position and use the toolbar at the bottom to add legs: +Stk (buy stock), −C (sell call), +P (buy put), etc.
  4. As you trade, close or roll legs to keep your position up to date.

Frequently Asked Questions

Stock prices aren't loading

PositionCashFlow uses the Polygon.io API (shown as "Massive" in the app) for market data. Check the following:

  1. Open the ellipsis menu (…) and tap Settings.
  2. Tap the eye icon to verify your API key is present and correct.
  3. Stock data uses the free tier, which provides the previous trading day's close. Prices won't update during weekends or holidays.
Option prices aren't loading

Option quote data requires a paid Polygon.io plan (Options Starter or higher). If you're on the free tier, stock prices will work but option leg prices will show an error. You can still record all trades manually — live pricing is optional.

How do I get a Polygon.io API key?

Visit polygon.io and create a free account. Your API key will be shown on the dashboard. Copy it and paste it into the Settings screen in the app. The free tier includes stock price data (previous close).

How do I import ThinkorSwim trades?

In ThinkorSwim, export your trade history as a CSV file. Then in PositionCashFlow:

  1. Tap + and choose Load CSV Data.
  2. Select your CSV file from the file picker.
  3. The app will parse and display the imported records.
  4. When adding legs to a position, use Fill from CSV to match imported entries.
What is "Position Value"?

Position Value is the estimated liquidation value of your position: what you'd receive if you closed all open legs at current market prices, combined with your net cashflow. For options, each contract represents 100 shares. If prices aren't available for all legs, Position Value won't be shown.

How do I roll an option?

Tap into a position, find the open leg you want to roll, and tap Roll. This closes the existing leg and opens a new one at the strike and expiration you choose. The net credit or debit is recorded as a single roll transaction.

How do I back up my data?

Tap the ellipsis menu (…) and choose Export Data. This creates a JSON file containing all your positions, legs, and transactions. Use the share sheet to save it to Files, AirDrop it, or email it to yourself. To restore, use Import Data and select the JSON file.

Can I delete a position or transaction?

Yes. Swipe left on any position in the list, any transaction in the detail view, or any closed leg to delete it. This action cannot be undone, so back up your data first if you're unsure.
